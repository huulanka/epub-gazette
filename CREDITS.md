| Libre Caslon Text | Pablo Impallari and the Libre Caslon Text Project Authors | body text |

Libre Caslon Text is distributed by Google Fonts as a variable font. The
static Regular, Bold and Italic instances in this repository were generated
from it with fontTools' `instancer`, because Kindle does not support variable
fonts. The font has no Reserved Font Name. License texts are in
`themes/klassisch-1900/fonts/licenses/`.

## Images
